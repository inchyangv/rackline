## 적용한 결정 ID·버전 / 가정 / OPEN 항목

- 적용: R2-D04(보조 서명/관찰 ≠ source 사실; 관찰은 등급을 올리지 못함), R2-D13(회수는 별도 — revoke는 draw 동결 의미이며 상환 경로를 막지 않음); GPU-013 §3(생성 registrar / E2 attest underwriter + PoC / observe oracle·servicer / revoke guardian / release servicer+treasury, debt==0 ∧ 대사 창 종료 ∧ refund 없음), §6(receiver 변경↔draw race: 새 version은 이전 관찰 무효 + `controlObservationMaxAge`; 오래된 release assertion 거부; 지원 override 관찰 → 비유효, 자동 default 없음).
- 가정: 차주 `AGREEMENT_CONSENT` 서명 기록은 오프체인/GPU-045 심사 입력이며 온체인 registry는 역할 결정만 기록(GPU-030 AuthorizationVerifier로 별도 검증). "debt>0 중 등급 하향/subject 축소 금지"는 facility가 funded version을 고정하는 GPU-036 manager 책임으로 둔다(registry는 version만 증가).
- 가정: authoritative debt = `IDebtLedger.legalDebtAt(facilityId, now)`(GPU-033 병렬 구현; 여기서는 stub). DEBT 미바인딩이면 release 불가(fail closed).
- OPEN: 없음(이 티켓). 실제 파트너 lock·override 가능성은 GPU-009/056.
