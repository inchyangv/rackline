**ERC-4626 적합성 선언**: 미구현. 일치: `asset()`, `totalAssets()`(=nav), `convertToShares/Assets`(virtual offset), ERC-20 share. 의도적 불일치: `deposit(assets,minShares)`/`withdraw(shares,minAssets)`는 slippage guard 포함·msg.sender 전용, `mint`/`redeem`/receiver/owner 변형 없음, `maxWithdraw`는 cash 한도. 4626 채택은 GPU-042(queue)·GPU-050(UI) 요구가 생기면 별도 결정.

**설계 결정(ordering contract)**: manager(GPU-036/039)가 단일 ledger writer. draw: `ledger.recordDraw` → `vault.lend` 같은 tx. repay: 토큰 도착 → `ledger.allocate` → `vault.onRepayment(result)`; vault는 도착을 잔고 증가로 실측하고 `applied+excess==received`를 검사(가짜 result로 cash 없이 기록 불가). vault는 ledger를 쓰지 않는다(AR-02/03: 두 번째 원장 없음).
