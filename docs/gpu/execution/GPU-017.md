## 적용한 결정 ID·버전 / 가정 / OPEN 항목

- 적용: R2-D04/D05(native 성공 ≠ 소유권/무담보/E2), R2-D13, PIVOT §6.1(UUID/serial/NIC/MAC, MIG, RMA, 다중 listing), §11(서류는 심사 입력), GPU-013 §1 역할(등록 operator/system, 심사·권리 underwriter), GPU-011 §2 `AccountKey`.
- 가정: 리스 자산은 `LEASE_CONSENT` 문서 참조가 있어야 적격; 제3자 LIEN/PLEDGE/ASSIGNMENT는 우선순위와 무관하게 적격 차단(우선순위 협상은 심사 판단, `PRIORITY_CONFLICT` flag 해소로 처리). 계정의 `provider_accounts.borrower_id`는 현재 바인딩, `provider_account_links`는 이력+심사 상태.
- OPEN: 실제 소유권/리스/UCC 서류 형식과 검토 절차(GPU-004/005/006 DD); RMA 시 파트너 계정 재등록 규칙(파트너 자료 필요).
