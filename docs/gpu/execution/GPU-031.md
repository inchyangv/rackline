## 적용한 결정 ID·버전 / 가정 / OPEN 항목

- 적용: R2-D01/D02(native 필수 경로 §0.9: GPU-078 → GPU-031), R2-D03/D04(서명·관리자 대체 불가; book에 진입점 없음), R2-D05(record ≠ 매출/현금/권리), R2-D06(validUntil은 proof 정책 유효기간; acceptance가 freshness를 늘리지 않음 — provenAt은 소비 시각), GPU-076 §3(소비 키 = sourceEventId, 경제 ID는 proof bytes/verifier/SDK와 무관 → verifier 교체 replay는 AlreadyConsumed).
- 가정: consumer allowlist는 ADMIN 관리(GPU-043 wiring에서 timelock 적용). pause는 GPU-043.
- OPEN(GPU-081로 이관): 같은 obligationRef의 revision 2+ `ObligationRecognized`가 domain-model §2 economicEventId(`…/OBLIGATION/{ref}`)와 충돌하지 않도록 revision을 ref에 포함하거나 CORRECTION 유형으로 매핑하는 규칙을 GPU-035/081에서 확정해야 함(book은 경제 ID 중복을 fail closed).
- 설계 메모: 부분 소비(instruction subset)를 허용 — 한 tx의 여러 log를 각각/나중에 소비 가능(EV-01). 배열 위치가 아닌 receipt ordinal로 매칭해 재정렬 위장을 막음.
