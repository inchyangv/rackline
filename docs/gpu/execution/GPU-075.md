## 실패/미실행과 이유

- CC3 **mainnet** probe 미실행: 공식 environments 페이지에 mainnet RPC URL이 없고 임의 URL을 만들지 않음 → PRODUCTION manifest 미작성(GPU-062).
- `proof-by-tx` 실제 호출 미실행: 실제 source tx 없이 임의 hash로 서비스를 호출하지 않음(응답 schema는 SDK 0.18.0 dist 코드에서 확인). 실제 proof 획득/검증은 GPU-080.
- decoder 배포 코드↔`EvmV1Decoder.sol` 동등성 미검증(verified source 링크 없음) → GPU-082.
- 공식 예제 저장소(`gluwa/attestcoin-protocol-examples`) 소스 대조는 하지 않음; 문서 인용 코드는 교육용으로만 취급.
- SOL-FULL/PY/WEB 미재실행: 해당 경로 무변경(GPU-000 기준선 유효).
